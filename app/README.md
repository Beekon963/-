# LIFE RANKED

人生をランクマッチにする。自分の行動が XP になり、ランクが上がる（サボると下がる）個人用ゲームアプリ。

- 公開 URL（main にマージ後）：`https://beekon963.github.io/-/life-rank/`
- スマホでは「ホーム画面に追加」して使う（iPhone は Safari の共有ボタン →「ホーム画面に追加」）

## ゲームのルール（初期値・設定画面で変更可）

| 行動 | XP |
|---|---|
| デイリー達成 ★ / ★★ / ★★★ | +20 / +40 / +60 |
| デイリーに着手（途中まで） | 半分（ペナルティなし） |
| デイリー3つ全達成（PERFECT） | +30 |
| 攻めの行動 30分 | +10 |
| 守りの業務 30分 | +2 |
| 小 / 中 / 大目標の達成 | +100 / +300 / +1000 |
| 週の目標 / 月の目標の達成（各1つ） | +100 / +300 |
| 挑戦ログ1件（成功・失敗・途中に関係なく） | +20 |
| 挑戦を発信した | +30 |
| 人脈「連絡した」・振り返り | +10 |
| 7日連続ボーナス | +50 |
| **降格**：手をつけていないデイリー（日付が変わった時点） | 1つにつき −15 |
| **降格**：デイリーを1つも設定しなかった日 | −50 |
| **降格**：明日のクエストを前日までに書かなかった | −30 |
| **降格**：来週の目標を日曜までに書かなかった | −100 |
| **降格**：来月の目標を月末までに書かなかった | −200 |
| 連続が途切れたあと戻ってきた日（COMEBACK・7日に1回まで） | +30 |
| タスク「大切」を完了 / 「今すぐ・先に・いつか」を完了 | +15 / +5 |

降格の数字は RANKED のときの値。試合モードで変わる（下の「続けるための仕組み」）。

- XP が減ればランクも下がる。XP は 0 未満にはならない
- 休息日は週1回まで（ペナルティなし・連続日数も途切れない）。使い始めた初日もペナルティ対象外
- 1日の切り替わりは朝4時（深夜の作業は前日扱い）
- 次のランクの XP に届いても、昇格条件が残っていれば「昇格戦」。条件を自分でクリアにすると昇格
- 挑戦回数＝達成・着手したデイリー＋挑戦ログ。ホームに今日・昨日・通算を表示
- 挑戦ログは「発信ネタ帳」を兼ねる。ネタ帳に入れた挑戦は投稿文をコピーできる
- 計画は「前日までに書く」：明日のクエストはその日のうちに、来週の目標は日曜までに、来月の目標は月末までに。クエストタブの「明日・今週・今月」か、夜の振り返りから書ける
- 計画のルールは、このルールが入った版を初めて開いた翌日から適用（過去の日はさかのぼって減点しない）

## 続けるための仕組み（三日坊主対策）

- **試合モード**（設定 → MATCH MODE。初期値は STANDARD）

  | モード | 減点 | 保険（自動の休息日） |
  |---|---|---|
  | CASUAL | なし | あり |
  | STANDARD | 半分・1日最大 −50 | あり |
  | RANKED | そのまま | なし |

  変えると過去の減点も計算し直される
- **最低ライン**：その日、クエストに1つ「着手」する、挑戦を1回記録する、タスク「大切」を1つ終える、のどれかで連続日数がつながる。ホームのクエストの上に表示
- **保険**：最低ラインを越えなかった日は、週の休息日の枠が残っていれば自動で休息日になる（減点なし・連続も切れない）。自分で休息日にした週は使えない
- **COMEBACK**：連続が途切れても、戻ってきた日に1つ手をつければ +30 XP
- 振り返りでは、最近のクエストをタップするだけで明日のクエストに入れられる

## タスク（4マス）

ホームの今日のクエストの下に、Yondo のような4マスのタスクボードがある。

- **今すぐ／大切／先に／いつか** の4つに分けて置く。マスの見出しをタップすると、そのマスの全部のタスクと追加欄（Enter で続けて追加）
- 丸をタップで完了。タイトルをタップすると、名前の変更・別のマスへの移動・「今日のクエストにする」・削除
- 完了したタスクは、その日のうちは線を引いて残り、翌日のボードから消える（XP の記録は戦績に残る）
- 減点はなし。「大切」は目標に近づくタスク用で、XP が多く、最低ラインにも数える

## ロック画面の壁紙

ランク・連続日数・今日のクエスト・4マスのタスクを1枚の画像にして、ロック画面の壁紙にする（設定 → LOCK SCREEN）。
iPhone のロック画面ウィジェットは小さく4マスが入らないので、壁紙にしている。

- **手動**：「今の画像を保存・共有」で画像を保存して、壁紙に設定する（ログイン不要）
- **自動**（ログインが必要）：壁紙にする iPhone で「自動更新をオンにする」。アプリで変えた内容が数秒で画像になり、
  今日・明日・明後日の分が Supabase Storage に日付ごとに置かれる（`…/wallpapers/ユーザーID/鍵/2026-10-24.jpg`）。
  iPhone のショートカットが決まった時刻にその日の画像を取りに行って壁紙にする

### ショートカットの作り方（最初の1回だけ）

1. 「ショートカット」アプリで「＋」→ 新しいショートカット
2. 「日付をフォーマット」：日付「現在の日付」、フォーマット「カスタム」、書式 `yyyy-MM-dd`
3. 「テキスト」：設定画面でコピーした URL ＋ 変数「フォーマット済みの日付」＋ `.jpg`
4. 「URLの内容を取得」
5. 「壁紙を設定」：画像は「URLの内容」、ロック画面だけ。「プレビューを表示」「被写体を切り抜く」はオフ
6. 「オートメーション」→「時刻」で 5:00・12:00・18:00・21:00 などを作り、「すぐに実行」でこのショートカットを選ぶ

- 画像の URL を知っている人は画像を見られる（URL に推測できない鍵が入っている。設定で作り直せる）
- 前に `schema.sql` を実行したことがある場合は、もう一度実行する（画像の置き場所と権限が追加されている）

## 通知

アプリ単体では閉じているときに通知を出せないので、カレンダーの通知を使う。
設定 → REMINDERS で時刻を決めて、「まとめてカレンダーに追加（.ics）」か、1つずつ「Googleに追加」。

| 通知 | いつ | 初期値 |
|---|---|---|
| 今日のクエストに1つ着手 | 毎日 | 7:30 |
| 振り返り＋明日のクエスト | 毎日 | 22:00 |
| 来週の目標を書く | 毎週日曜 | 21:00 |
| 来月の目標を書く | 毎月末 | 21:00 |

## 人生の目標（VISION）

ホーム上部のミッションをタップすると、人生の目標・理由・価値観・到達目標・究極の夢・毎日の行動指針が見られる。
内容は端末（ログイン中はアカウント）にだけ保存され、このリポジトリには含まれない。
用意した初期データ（JSON）は「設定 → バックアップ・初期データを読み込む」から取り込める。

## ログイン・同期の準備（Supabase・無料）

スマホと PC で同じデータを使うために、無料の Supabase を使う。最初の1回だけ。

1. https://supabase.com でアカウントを作り「New project」を作成（Region は Tokyo）
2. 左メニュー **SQL Editor** を開き、[`supabase/schema.sql`](supabase/schema.sql) の中身を貼り付けて **Run**
3. **Authentication → Sign In / Providers → Email** で「Confirm email」をオフ（個人用なので確認メール不要）
4. **Project Settings → API Keys** で次の2つを控える
   - Project URL（`https://xxxx.supabase.co`）
   - `anon` `public` キー（または `sb_publishable_...` で始まるキー）
5. アプリを開き、URL とキーを入力 →「アカウント作成」→ ログイン
6. 自分のアカウントを作り終えたら、**Authentication → Sign In / Providers** で「Allow new users to sign up」をオフ（他人が登録できないように）

- anon / publishable キーは公開されても大丈夫な鍵（行レベルセキュリティで自分のデータしか読めない）。**`service_role` / secret キーは絶対に貼らないこと**
- URL とキーを `app/.env` に書いてビルドすると、入力画面を省略できる（`.env.example` 参照）
- 無料プランは1週間アクセスがないと一時停止される。毎日使っていれば問題なし

## 開発

```bash
cd app
npm install
npm run dev        # 開発サーバー
npm test           # ゲームロジックのテスト
npm run build      # ../life-rank/ にビルド（これをコミットすると GitHub Pages に反映）
```

### 構成

- `src/lib/game.ts` … XP・ランク・降格・連続日数の計算（XP は保存せず、記録から毎回計算）
- `src/lib/reminders.ts` … 通知用のカレンダー（.ics・Google カレンダーのリンク）
- `src/lib/wallpaper.ts` / `src/store/wallpaper.ts` … ロック画面の壁紙を描く・Supabase Storage に置く
- `src/store/data.ts` … 端末内のデータ（IndexedDB）
- `src/store/cloud.ts` … Supabase のログインと同期（端末で変更 → 送信 → 差分を取り込み）
- `src/screens/` … 各画面
- `supabase/schema.sql` … データベースの定義
